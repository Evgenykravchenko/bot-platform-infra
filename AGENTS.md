# Релизы и эксплуатация

- GitHub Releases всегда оформлять по образцу [BotCRM v0.4.3](https://github.com/Evgenykravchenko/botcrm/releases/tag/v0.4.3): вводный абзац, конкретные изменения списком, подтверждённые проверки, ссылка на инструкцию в выпущенном теге, номера PR.
- Для этого репозитория тег — `v<SemVer>`, название релиза — `Bot Platform Infra v<SemVer>`. Не заменять описание одной строкой или автоматически сгенерированными заметками.
- Защиту main не обходить: отдельная ветка, Conventional Commits, PR и обязательные проверки.
- Диагностика хоста выполняется только вручную из main, без изменения служб, конфигурации, томов или состояния Tailscale. Не выводить секреты и сырые журналы.
- Не запускать deploy общего Compose ради изменения workflow или диагностического скрипта. Другие проекты не перезапускать.
