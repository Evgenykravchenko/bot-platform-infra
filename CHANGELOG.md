# Changelog

Изменения фиксируются в GitHub Releases по принятому шаблону проекта.

## 0.3.1 — 2026-10-29

- Ручная диагностика SSH и LAN через установленный runner, если внешний SSH недоступен. Службы, контейнеры и настройки не меняются.
- Вывод ограничен состоянием служб и частными адресами физических интерфейсов; добавлены проверки фильтрации диагностических данных и входного IPv4.

## 0.3.0 — 2026-10-29

- Ручная выкатка утверждённых релизов BotCRM через существующий infrastructure runner, без зависимости от локального SSH.
- Проверка полного SHA, тега и принадлежности main перед штатным blue/green-развёртыванием BotCRM. Общий Compose и другие боты не перезапускаются.
- Тесты отказа при изменённом checkout, неверной версии, несовпадающем SHA и теге вне main.
